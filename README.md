A fast drop-in replacement for csv-reader 1.0.0: `run(input)` returns exactly
the same {columns, rows, errors} reading of a broken CSV text — BOM handling,
stray CRs, quote junk, unterminated quotes, short/long row errors — produced
with a hand-scanned field loop and whole-segment slicing instead of
one-character-at-a-time concatenation.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
